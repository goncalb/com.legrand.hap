My gateway isn't listed — show all HomeKit bridges Device not listed? Pair by HomeKit id and IP address

Get both from the hap-probe "discover" output on a computer in the same network.

The setup code is printed on the gateway's label, or shown in the Home + Control app under the gateway's HomeKit section. If the gateway shows as already paired, remove it from Apple Home first (Home settings → Hubs & Bridges) — a HomeKit bridge accepts a single controller.
